# 설정 화면의 준비 상태와 모델 다운로드

> 구현은 현재 작업 폴더에서 순서대로 진행한다. 기존 설치 스크립트·README 변경을 유지한다.

**목표:** 기존 설정 화면에서 음성 모델·FFmpeg·워커·분석 도구의 상태를 확인하고 모델 다운로드와 재시도를 실행한다.

**승인 범위:** 이번 대화에서 승인한 설정 화면 개선이다. 휴대폰 HTTPS·QR 연결은 다음 작업이다.

**후속 범위 변경:** 휴대폰 브라우저 녹음과 HTTPS·QR 연결은 진행하지 않는다. 휴대폰의 녹음 앱에서 저장한 파일을 서버 PC로 옮겨 기존 파일 가져오기를 사용한다.

**구조:** 기존 모델 준비 함수와 처리 프로세스 관리 코드를 재사용한다. 다운로드는 API가 관리하는 별도 작업으로 실행하므로 전사 워커가 없어도 동작한다. 추론과 모델 쓰기는 같은 파일 잠금으로 순서를 보장한다. 브라우저가 보내는 값은 고정된 음성 모델 이름뿐이며 임의 URL·명령은 받지 않는다.

**기술:** FastAPI, subprocess, fcntl, Hugging Face의 공개 tqdm 확장점, React, 기존 CSS.

## 제약과 검토 항목

- 정상 종료·실패·서버 종료 때 다운로드 자식 프로세스를 정리한다.
- 다운로드 중 페이지를 나갔다 돌아와도 진행 상태를 조회한다.
- 모델 다운로드가 끝난 뒤에만 준비 완료로 표시한다. 실패한 재다운로드의 이전 manifest를 준비 완료로 사용하지 않는다.
- 진행률은 실제 파일 수다. 알 수 없는 전체 수와 검증 단계는 수치 없이 표시한다.
- 모델 다운로드 폴링이 분석 설정의 미저장 편집 내용을 초기화하지 않는다.
- 로그인·키 설정 확인을 실제 유료 모델 호출의 성공으로 표현하지 않는다.
- 녹음·전사·원본 음성은 변경하거나 삭제하지 않는다.
